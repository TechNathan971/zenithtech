# ZenithTech

A learning project: a multi-page fintech marketing site built with Next.js, plus a backend and a full DevOps pipeline. Not a real product and not hosted publicly.

## Stack

- Next.js (Pages Router), React, TypeScript
- Tailwind CSS
- PostgreSQL + Prisma (added in a later step)
- Docker, GitHub Actions, Kubernetes (DevOps phase)

## Scripts

| Command                | What it does                                  |
| ---------------------- | --------------------------------------------- |
| `npm run dev`          | Start the dev server on http://localhost:3000 |
| `npm run build`        | Production build                              |
| `npm run lint`         | ESLint                                        |
| `npm run typecheck`    | TypeScript check                              |
| `npm run format:check` | Prettier check                                |
